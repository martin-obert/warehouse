## Project Overview

Warehouse is a Nuxt 4 web application using Vue 3 and Vue Router 5. It uses npm as the package manager.

## Commands

- `npm run dev` — start dev server at http://localhost:3000
- `npm run build` — production build
- `npm run preview` — preview production build locally
- `npm run generate` — static site generation
- `npm run postinstall` — runs `nuxt prepare` (generates `.nuxt/` types)

## Architecture

This is a Nuxt 4 project using the default directory structure:

- `app/` — application layer (entry point: `app/app.vue`)
- `src/` — non-Nuxt source code
- `public/` — static assets served at root (`favicon.ico`, `robots.txt`)
- `nuxt.config.ts` — Nuxt configuration (devtools enabled)

TypeScript config is generated by Nuxt into `.nuxt/tsconfig.*.json` and referenced from the root `tsconfig.json`. Run `nuxt prepare` after cloning to generate these before type-checking.

The project is configured as ESM (`"type": "module"` in package.json).

For current structural detail (data model, API surface, directory layout) see `docs/ARCHITECTURE.md` instead of re-exploring the codebase from scratch.

3. Update `docs/ARCHITECTURE.md` if directory structure, schema, or the API surface changed.
